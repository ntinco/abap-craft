# Editorial support

This folder contains publication-plane support artifacts, not AI governance.

- `editorial-voice.md` — human-owned voice and positioning guidance that is costly to reconstruct.
- `templates/` — reusable input/front-matter shapes.

AI operating rules live in `ai/governance.md`; routing lives in `ai/repo-map.json`. A capable agent should derive routine writing, translation and publishing execution from those contracts plus the task intent instead of loading a stack of overlapping prompts.
